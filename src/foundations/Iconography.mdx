# Iconography

ABOVE is almost icon-free — the system leans on type, scale and void instead of UI chrome.

- **Logotype vs symbol.** The full *ābove* logotype is the stand-alone unit: when nothing else signals the brand, write out the full word. The *ā* symbol is used when other Above signifiers are present, like a tagline ("Innovation, Design & Technology"). Both come in black and white. The `Logo` component is the symbol; the logotype SVG still needs to be added to the repo from the Figma file.
- **The mark — ā.** A lowercase grotesque *a* with a macron above it ("Above"). Single path, uses `currentColor` so it flips with the ground. Never redraw it.
- **The header tab.** The 42×9 solid rectangle that opens the chapter bar — a wordless "you are here" tick.
- **Typographic glyphs as illustration.** Single characters from the display face stand in for imagery, e.g. ✌ at 560px on the closing slide.
- **Icons are heavy and geometric.** Per the brand guidelines, iconography contrasts with the light typeface: bold, geometric, curved and angular on the same symbol (see Graphics & 5th element). Avoid thin monoline icons — they don't contrast enough with the type. (The deck-only source suggested Lucide as a fallback; the guidelines supersede that.)
