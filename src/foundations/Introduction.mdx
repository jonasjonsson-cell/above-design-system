# ABOVE Design System

ABOVE's system, built from three sources: the brand guidelines in the "Above Design System
Exploration" Figma (Above Presentation Template library), the "Visual Design Weekly" deck
template, and above.se. Swiss, type-led, mostly monochrome — spacious white layouts with
high-contrast typography, one green highlight, and the dash as the 5th element.

## Principles

- **Mainly monochrome, one highlight.** Black, white and four greys, plus Primary green (`#9fe59a` and two
  darks) as the one key highlight. Secondary blue/violet/sky/coral only support content. No tints, no gradients.
- **Two type roles, extreme contrast.** Suisse BP Int'l for display (weight 400, line-height 0.8,
  negative tracking) and KH Interference for the 12px uppercase mono label.
- **Hard edges.** Radius 0 everywhere. The tilted photo card is the only ornament, and the only place
  a radius, border or shadow appears.
- **Hard cuts.** No easing or bounce. Interaction is an instant invert or opacity shift.
- **Voice.** Sentence case, fragments, one idea per slide, numerals as graphics, the occasional
  Swedish word ("Tack!"). No emoji as UI.

## How it fits together

- `src/styles/tokens.css` is the single source of truth. Brand tokens use the same names as the
  Claude Design system (`--black`, `--fg1`, `--font-display`, `--type-hero`…) and feed theme-aware
  semantic tokens (`--color-*`, `--font-size-*`, `--space-*`…) that the components read.
- `data-theme="light"` switches to the inverted off-white cover ground.
- The Figma library variables are generated from the same tokens.

## What's here

- **Foundations** — color (palette, distribution, combinations, emphasis), typography (text styles, families, weights), spacing & radius, layout, graphics & the 5th element, voice & content, iconography.
- **Components** — HeaderBar, PhotoCard, Display, Label, Logo, Dash (5th element), Tag, ArrowButton, and Button.
- **Slides** — the "Visual Design Weekly" deck template: `Slide` plus Cover, Section, Agenda, Statement, Photo, Summary and Closing templates, and the full 10-slide sample deck.

> Button, the UI type scale and the 4px spacing scale are additions for interface work — they aren't in the source deck material.
